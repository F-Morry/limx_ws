# limx_ws
逐际WF_TRON1A机器人导航开发,其中源码来自于逐际动力官方开发源码，主要工作为从设计里程计开始完成导航开发。
由于机器人自身所采用差速里程计存在一定缺陷：当其中一个轮子卡住，另一轮子转动时，里程计仍会进行里程计算，从而带来误差不满足导航开发需求，因此需要额外设置一个里程计以满足开发需求
## 里程计开发
我们为WF_TRON1A外接了一个雷神N10p系列激光雷达，在此基础上利用激光雷达数据进行里程计估计，所采用的算法为R2FO，其来源为https://github.com/MAPIRlab/rf2o_laser_odometry
是一种2d激光雷达估计里程计算法。
